### 1-5. 접근성 공통 규칙

- 모든 인터랙션 요소의 최소 터치 영역은 **44×44px** 이상.
- 키보드 포커스는 `:focus-visible`에 2px `color.ink` 또는 `color.coral` 아웃라인 + 2px 오프셋으로 항상 표시하고, 마우스 클릭 시에는 표시하지 않는다.
- 색상 단독으로 상태를 구분하지 않고 텍스트 라벨(예: "확인 필요", "모집중", "마감")을 항상 병기한다.
- 이미지 `alt`는 실제 장소·상황을 설명하는 문장으로 작성한다(예: "제주 성산일출봉과 유채꽃밭 전경").

## 3. Section 배치 원칙 요약

- 모든 화면은 Header–Section 1~N–Footer 순서로 배치하며, Section 사이 구분은 배경 톤 교차(`canvas` ↔ `surface-soft`)로만 표현하고 그림자·굵은 구분선은 쓰지 않는다.
- SCR-001, SCR-002 = 7개 Section / SCR-003, SCR-004 = 6개 Section. SCR-005는 역할별 탭 구조라 Section 수를 고정하지 않되, 같은 Header/Footer와 여백 규칙을 따른다.
- Hero는 Desktop 기준 520~560px 높이로 제한해 1440px 화면에서 다음 Section 상단이 보이도록 한다.
- 아래 표의 "패턴"은 `Hero / Card Grid / 좌우 분할 / Chip 목록 / 3단계 안내 / CTA Banner / Timeline / Gallery / Form` 중 교차 사용한다.
- 데이터가 없는 경우에도 안내 문장 + 이용 방법 + 다음 행동 CTA를 갖춘 Empty State를 사용하고, "준비 중"·"정보 확인 필요"·빈 카드·Lorem ipsum은 쓰지 않는다.

## 6. SCR-003 `/travel-tools` 통합 여행 준비

**사용자 목표:** 항공·숙소 조건을 정리해 외부 사이트로 이동하거나 동행 모집글을 작성한다.

| # | Section | 패턴 | 제목(예시) | 설명(1~3문장) | 콘텐츠/CTA | Requirement |
|---|---|---|---|---|---|---|

## 8. SCR-005 `/account` 계정·관리

**사용자 목표:** 로그인·회원가입·성인 확인을 완료하고 내 프로필과 활동을 관리하며, 관리자는 신고와 외부 URL을 처리한다.

역할에 없는 탭은 렌더링하지 않는다. 탭 노출 조건은 아래와 같다.

| 역할 | 노출 탭 |
|---|---|
| Guest(비로그인) | 로그인·가입 |
| Adult Member | 프로필, 내 활동 |
| Moderator/Admin | 프로필, 내 활동, 관리자 |

### 8-1. Guest 탭 — 로그인·가입

| 영역 | 내용 |
|---|---|
| Intro | "Free Traveler 계정으로 할 수 있는 일" — 동행 글 작성·참가 요청·즐겨찾기 저장이 가능하다는 2문장 안내 |
| 로그인 Card | 이메일·비밀번호 입력, "로그인" Primary CTA, 비밀번호 재설정 링크 |
| 가입 Card | 이메일·비밀번호·닉네임 입력, 이메일 인증 안내, "가입하기" CTA |
| 로그인 후 가능한 기능 | Chip 목록(동행 글 작성, 참가 요청, 즐겨찾기, 신고·차단) |
| 보안 안내 | "비밀번호는 안전하게 암호화되어 저장됩니다"와 같은 신뢰 문구 + 개인정보 처리방침 링크 |

### 8-2. Adult Member 탭 — 프로필 / 내 활동

**프로필 탭**

| 영역 | 내용 |
|---|---|
| 프로필 요약 | 닉네임, 연령대, 여행 스타일, 성인 확인 상태 배지("확인 완료" `color.success` / "확인 필요" `color.warning` + CTA) |
| 편집 Form | 닉네임·연령대·성별(선택)·여행 스타일·자기소개 수정 |

| Section | 내용 | Empty State |
|---|---|---|

### 8-3. Moderator/Admin 탭 — 관리

| 영역 | 내용 |
|---|---|
| 관리 Intro | "신고 처리와 외부 링크 설정을 관리합니다"라는 1문장 안내(대시보드·통계 없음) |

| 상태 | 적용 범위 | 내용 |

## 10. Dashboard/복잡한 통계 화면 제외 확인

- SCR-005 관리자 탭은 신고 목록·상태 변경, 외부 URL 설정만 제공하며 별도의 통계 대시보드, 그래프, KPI 위젯을 두지 않는다.
- SCR-002의 "여행 지표"(50+/30+) Section은 통계 대시보드가 아닌 3개 Stat 카드로 제한한다.
- 모든 화면의 Loading/Empty/Error/Unauthorized 상태는 위 표에 정의된 범위 내에서만 사용하고, 화면별로 필요하지 않은 상태(예: SCR-002의 Unauthorized)는 정의하지 않는다.
